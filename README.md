## 💻 Projetos Pessoais
Abaixo destaco algumas das soluções analíticas documentadas que podem ser exploradas no meu perfil:
* **Mercado Automotivo (`sql-mercado-automotivo`):** Análise de risco e métricas de precificação combinando limpeza de dados em banco relacional e construção de dashboard no Power BI.
* **Detecção de Intrusão em Redes (FATEC):** Preparação de dados e análise exploratória e diagnóstica sobre uma base de +25 mil registros para identificação de ameaças de cibersegurança.
* **Estudos Financeiros e Macroeconômicos:** Comparativos de performance de ativos (ITUB4, estudo normalizado de Bitcoin vs. Ibovespa) utilizando as bibliotecas financeiras do Python e conexão com a API do Banco Central.
* **Mercado Global de Video Games:** EDA (Análise Exploratória de Dados) aprofundada utilizando recursos estatísticos de Pandas, Matplotlib e Seaborn.
